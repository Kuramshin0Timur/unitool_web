# Рефакторинг app.py

## Обзор изменений

Оригинальный файл `app.py` (6115 строк) был разделен на модульную структуру для улучшения читаемости, поддерживаемости и организации кода.

## Новая структура проекта

```
unitool_web/
├── app.py (оригинальный файл - резервная копия)
├── app_original_backup.py (резервная копия)
├── app_final.py (новая версия)
├── routes/
│   ├── __init__.py
│   ├── main.py (основные маршруты)
│   ├── auth.py (аутентификация)
│   ├── pages.py (страницы)
│   ├── api_reserve_tokens.py (API резервных токенов)
│   ├── api_campaigns.py (API кампаний и адсетов)
│   ├── api_autocontrol.py (API автоконтроля)
│   └── api_additional.py (дополнительные API)
├── utils/
│   ├── __init__.py
│   ├── decorators.py (декораторы)
│   └── helpers.py (вспомогательные функции)
└── models/
    ├── __init__.py
    └── reserve_tokens.py (модели для резервных токенов)
```

## Описание модулей

### Routes (Маршруты)

#### `routes/main.py`
- Основные маршруты приложения
- Главная страница, дашборд, кампании, адсеты
- Настройки, выход из системы

#### `routes/auth.py`
- Маршруты аутентификации
- Вход и регистрация пользователей
- Управление сессиями

#### `routes/pages.py`
- Маршруты страниц интерфейса
- Автоконтроль, резервные токены
- Добавление кампаний и адсетов
- Мониторинг баланса, оптимизация заголовков

#### `routes/api_reserve_tokens.py`
- API для работы с резервными токенами
- CRUD операции с токенами
- Управление аккаунтами токенов
- Обновление KING и токенов

#### `routes/api_campaigns.py`
- API для работы с кампаниями и адсетами
- Получение, обновление, удаление
- Управление статусами
- Синхронизация с внешними сервисами

#### `routes/api_autocontrol.py`
- API для системы автоконтроля
- Запуск/остановка автоконтроля
- Управление автообновлением
- Получение статуса и логов

#### `routes/api_additional.py`
- Дополнительные API маршруты
- Обновление GEO адсетов
- Перенумерация KING
- Управление правилами GEO

### Utils (Утилиты)

#### `utils/decorators.py`
- Декораторы для проверки аутентификации
- `@login_required` - основной декоратор

#### `utils/helpers.py`
- Вспомогательные функции
- `auto_determine_king()` - определение платформы по токену
- `get_account_limits_info()` - получение лимитов аккаунта
- `split_clean()` - очистка и разделение строк

### Models (Модели)

#### `models/reserve_tokens.py`
- Модели для работы с резервными токенами
- `get_reserve_tokens()` - получение токенов пользователя
- `get_reserve_tokens_table()` - данные для таблицы
- `get_all_accounts_stats()` - статистика аккаунтов

## Миграция

### Для запуска новой версии:

1. **Резервная копия создана**: `app_original_backup.py`
2. **Новая версия**: `app_final.py`
3. **Для активации**: замените `app.py` на `app_final.py`

### Команды для активации:

```bash
# Создание резервной копии (уже сделано)
cp app.py app_original_backup.py

# Активация новой версии
cp app_final.py app.py

# Или запуск напрямую
python app_final.py
```
